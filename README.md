# Siren Client (Fabric, Minecraft 1.21.11)

1. Push this folder to GitHub. Actions > Build > Artifacts > `siren-client` has the jar.
2. Install Fabric Loader 0.18+ for 1.21.11. Put the jar and Fabric API in `mods/`.
3. In game press **R** (rebind in Controls > Siren Client) to open the menu.

Tabs: Modules, Blocks (custom lists), Results (ranked hits, save as waypoint, export), Waypoints, Settings.
Config: `config/siren-client.json`.
